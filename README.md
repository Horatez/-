# Отраслевой аналитический конструктор показателей предприятия

Веб-приложение: ввод баланса и отчёта о финансовых результатах по годам, расчёт
показателей, сравнение с отраслью (ОКВЭД × размер бизнеса), тренды, таблицы,
графики, дашборд, экспорт. Система показывает только факты, отклонения и
динамику — без рекомендаций, прогнозов и оценок «хорошо/плохо».

## Запуск

Нужен только Python 3.10+ (внешних библиотек нет).

```bash
python3 server.py --port 8000
```

Откройте http://127.0.0.1:8000. При первом запуске создаются база `data/app.db`,
справочники, учётные записи из `seed_users.json` и учебное предприятие.

**Перед рабочим использованием:** смените пароли (в `seed_users.json` — тестовые)
и загрузите фактические отраслевые значения — версия справочника v1 содержит
демонстрационные числа.

Доступ из сети: `--host 0.0.0.0`, но только за обратным прокси с HTTPS.

| Роль | Права |

| Аналитик | карточки, ввод/импорт данных, расчёты, отчёты |
| Руководитель | просмотр отчётов, дашбордов, истории; экспорт |

## Правила расчёта

- Расходы вводятся положительными числами. Пустые итоги считаются автоматически;
  введённый итог, не равный сумме строк, и расхождение актива с пассивом
  показываются как замечания.
- Краткосрочные обязательства в коэффициентах ликвидности: стр. 1500 − стр. 1530.
- Среднегодовые величины (ROA, ROE, оборачиваемость): (начало + конец года) / 2;
  для первого года периода — значение на конец года (помечается в расшифровке).
- EBITDA: введённая, иначе стр. 2300 + стр. 2330 + амортизация; без амортизации
  показатели по EBITDA не рассчитываются.
- Положение: ниже нижней границы диапазона — «ниже», выше верхней — «выше»,
  иначе «в диапазоне». Отклонение — от выбранной базы (среднее или медиана).
- Тренд: изменение год к году менее 5 % — стабильность; все изменения в одну
  сторону — рост/падение; разнонаправленные — нестабильность. CAGR считается при
  положительных первом и последнем значениях.

## Импорт

Excel (.xlsx) или CSV вида `Код; Наименование; 2022; 2023; 2024`, где код —
код строки отчётности (1150, 2110 …) либо `headcount`, `amort`, `ebitda`,
`taxes`. Готовый шаблон — кнопка «Шаблон / выгрузка Excel» на вкладке ввода.
Отраслевые значения: CSV `industry;size;indicator;mean;median;low;high`
(образец — «Выгрузить версию в CSV»); загрузка создаёт новую версию справочника.

## Экспорт

Excel — отчёт с расчётами; CSV — исходные данные; PNG — графики и дашборд;
PDF — кнопка «PDF (печать)» в отчёте → «Сохранить как PDF» в диалоге браузера.

## Данные и безопасность

Пароли — PBKDF2-SHA256; сессии — HttpOnly-cookie, SameSite=Strict; блокировка
после 5 неудачных входов; все действия пишутся в журнал. Резервная копия базы —
раз в сутки и по кнопке, в `data/backups` (хранятся 30 последних). Каждый расчёт
сохраняется со снимком исходных данных, версией справочника и версией ядра.
